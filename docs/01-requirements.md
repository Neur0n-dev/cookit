# 01. 요구사항

## 기능 요구사항 (Functional Requirement)

| ID | 기능 | 상세 |
|---|---|---|
| FR-01 | 회원가입 | 아이디·닉네임 중복 확인 |
| FR-02 | 로그인·로그아웃 | JWT 발급 |
| FR-03 | 아이디 찾기 | 이름 + 닉네임으로 조회, 결과 일부 마스킹 (예: coo***) |
| FR-04 | 비밀번호 찾기·재설정 | 아이디 + 이름으로 본인 확인 후 재설정 토큰 발급, 토큰으로 재설정. 아이디 찾기·재설정 요청은 IP당 하루 5회 제한 |
| FR-05 | 회원정보 수정 | 이름, 닉네임, 비밀번호 변경 |
| FR-06 | 회원 탈퇴 | 소프트 삭제 (delete_flag = Y), 탈퇴 후 로그인 불가 |
| FR-07 | 내 재료 관리 | 등록·수정·삭제, 유통기한·메모 |
| FR-08 | 레시피 추천 | 재료 입력, 내 재료 불러오기(회원), 식단 모드(밸런스·다이어트·초간단), 추천 개수 선택. 비회원 사용 가능 |
| FR-09 | 추천 요청 제한 | 하루 기준 비회원 IP당 5회, 회원 30회. 횟수는 Redis에 저장해 WAS 간 공유 |
| FR-10 | 레시피 상세 | 필수·선택 재료, 조리 단계, 팁, 칼로리. 로그인 시 내 재료 기준 보유·부족 표시 |
| FR-11 | 즐겨찾기 | 저장·삭제, 검색, 상세 보기, 같은 레시피 중복 저장 방지 (회원 전용) |
| FR-12 | 검색 기록 | 추천 요청 이력 저장 |
| FR-13 | 응답 서버 표시 | 화면 하단에 요청을 처리한 WAS 표시 (예: served by cookit-was01) |
| FR-14 | 인기 레시피 랭킹 | 메인 화면에 인기 레시피 TOP 5 표시, 클릭 시 상세 팝업. 레시피 이름 기준으로 추천 +1, 즐겨찾기 +3(해제 시 -3) 점수를 Redis Sorted Set에 누적 |

**추후 작업**

1. 최근 검색 재료 표시
2. 유통기한 임박 표시
3. 소셜 로그인 (QR·간편 로그인, 고도화 단계)
4. 새로 추천받기 (추천 캐시를 건너뛰고 Gemini를 다시 호출해, 같은 재료로 다른 레시피 확인)

## 비기능 요구사항 (Non-Functional Requirement)

| ID | 구분 | 요구사항 |
|---|---|---|
| NFR-01 | 가용성 | 1·2단계: 장애 시 자동 알림, 중단 시간 기록<br>3단계: 서버 1대 장애 시에도 서비스 유지 |
| NFR-02 | 배포 | 1·2단계: GitHub Actions 자동 배포<br>3단계: 롤링 배포로 서비스 무중단 |
| NFR-03 | 관측 | 장애 발생, 인증서 만료 임박 시 자동 알림 수신 |
| NFR-04 | 성능 | 동일 재료 조합 재검색 시 캐시로 즉시 응답 |
| NFR-05 | 보안 | 비밀번호는 BCrypt 해시로 저장, 비밀번호 재설정 시 재설정 토큰으로 본인 확인, 서버 접근은 SSH 키 인증<br>2단계부터 HTTPS 적용, HTTP 접속은 HTTPS로 리다이렉트 |
| NFR-06 | 재현성 | Ansible 코드로 서버 설정 관리, 재구축 시 동일 상태 복구 |
| NFR-07 | 로깅 | 전체 로그를 Loki로 수집, 요청마다 요청 ID를 붙여 LB → WAS 구간 추적 |
| NFR-08 | 백업·복구 | DB 하루 1회 백업, 7일 보관, 복구 테스트 1회 이상 수행 |
| NFR-09 | 비밀 정보 관리 | DB 비밀번호·JWT 키·Gemini API 키 등은 저장소에 포함 금지, 앱용은 GitHub Secrets, 서버 구성용은 Ansible Vault로 관리 |
| NFR-10 | 외부 API 장애 대응 | Gemini 호출 30초 타임아웃, 실패 시 사용자 안내 메시지 표시 |
| NFR-11 | 시간 동기화 | 전체 서버 시간대 Asia/Seoul, chrony로 NTP 동기화 |

**비고**

1. 목표 수치는 [00 기획의 단계별 완료 기준](00-project-overview.md#완료-기준) 참고
2. 확장성: WAS는 Stateless로 설계(JWT 인증, Redis 공유)해 서버 추가만으로 수평 확장 가능
